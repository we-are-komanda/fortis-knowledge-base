# Единый локальный запуск Fortis

Принято 2026-10-20 по запросу пользователя после повторных остановок отдельного backend.

Команда из parent workspace: `make dev`. Реализация: `scripts/dev.py`, Python standard library, без новых зависимостей. Сначала запускается backend с существующим `backend/.env`, проверяется `/_/readiness` (включая БД), затем frontend workspace на localhost:3000 с backend origin 127.0.0.1:8090. Готовность frontend проверяется через прокси запроса проектов.

Supervisor остаётся запущенным до Ctrl+C/SIGTERM; останавливает собственные группы процессов. При завершении сервиса — до трёх перезапусков за сессию. При ошибке startup/readiness или исчерпании попыток завершает оба сервиса, оставляет диагностику. Занятые порты 3000/8090 вызывают отказ без завершения чужих процессов. Логи в игнорируемой `.fortis-dev/`; env/secrets в Git не добавляются.

PostgreSQL должна быть запущена и настроена заранее. Не добавлены автозапуск при входе в macOS, установка зависимостей, управление PostgreSQL или отдельный запуск миграций. Обычная инициализация backend сохраняется. Зависший, но не завершившийся процесс не перезапускается автоматически; проверка готовности действует при старте/перезапуске.

Проверки: `make test-dev` — 4 теста (занятый порт, преждевременное завершение, readiness, timeout и cleanup). Реальный совместный запуск прошёл; после SIGTERM backend supervisor поднял новый процесс, запрос проектов через frontend вернул HTTP 200.
