# Fortis `/prototype`: Felt-like GIS workspace UX — 2026-07-29

**Статус:** применено как runtime-направление для `/prototype` после входящей спеки и HTML-макета `Fortis_GIS_interactive_mockup.html`.

## Решение

`/prototype` должен использовать Felt-like модель рабочего пространства без визуального копирования Felt:

- верхний AppBar с контекстом объекта, режимами `Конфигурация / Аудит / Сравнение`, стоимостью, статусом бюджета и действием отчёта;
- одна левая рабочая панель с режимами `Структура / Библиотека`;
- карта остаётся центральной рабочей областью, без постоянных больших карточек поверх карты;
- правый инспектор скрыт по умолчанию и открывается только после выбора эшелона или размещённого объекта;
- нижняя аналитическая панель появляется в режимах `Аудит` и `Сравнение`, а не занимает место постоянно;
- режимы audit/compare используют ту же карту и переключают аналитический контекст, не создавая отдельный продуктовый flow.

## Применение

Первая реализация выполнена во frontend runtime `/prototype`:

- `src/modules/drone-defense/ui/drone-defense-prototype.tsx`;
- `src/modules/drone-defense/ui/drone-defense-prototype.module.css`;
- contract-check `src/modules/drone-defense/domain/catalog-sidebar-motion-contract.test.mjs` обновлён под новую сворачиваемую рабочую панель.

Второй прогон после UX-вердикта фиксирует P0-композицию:

- нижняя карусель эшелонов убирается из default-состояния конфигурации;
- дублирующая карточка объекта поверх карты скрывается в `/prototype`;
- глобальный vertical rail `DefenseStudioShell` не показывается на `/prototype`;
- пустая конфигурация показывает onboarding `выберите эшелон -> откройте библиотеку -> разместите средство`, а CTA называется по активному эшелону;
- стоимость пустой конфигурации отображается как `0 ₽`, бюджет как `Не задан`, аудит как `Не запускался`;
- границы эшелонов на карте трактуются как проектные зоны: слабая заливка и тонкая цветная линия, без имитации готового покрытия средств;
- стартовый фокус карты смещается к объектному масштабу предприятия.

P1 после стабилизации каркаса: критические зоны на карте, легенда, tooltips инструментов, компактный basemap control и отдельный региональный обзор внешних эшелонов.

## Ограничения

Текущий инспектор остаётся read-first. Полноценное редактирование всех типов объектов не расширялось: для МОГ сохранён существующий редактор, но он открывается явным действием из инспектора.

Backend-backed демо при локальной визуальной проверке требует валидную backend-сессию; тестовая cookie проходит только proxy-gate и может давать `invalid token` в API-зонах.


## Уточнение управления боковой панелью — 2026-10-21

По комментарию пользователя кнопка сворачивания всей левой панели перенесена из блока библиотеки в заголовок «Моя карта». В закрытом состоянии на карте остаётся кнопка «Развернуть боковую панель». Используется прежнее состояние isCatalogTrayOpen; поиск и содержимое сохраняются. Скрытая панель inert и исключена из accessibility tree; фокус передаётся между кнопками сворачивания/открытия. Обе кнопки имеют область нажатия 44×44 px. Данные проекта не меняются.

Проверено: scoped ESLint и test/playwright/sidebar-collapse.cjs прошли. В браузере проверены ширины 1068/390 px, сворачивание до нулевого размера, открытие с Enter, перенос фокуса, сохранение поиска и отсутствие API-записей/ошибок страницы. Полная сборка для этой локальной UI-правки не запускалась.

## «Моделирование» в общей навигации — 2026-10-21

По уточнению пользователя пункт «Моделирование» в левой навигации открывает **`/prototype?view=scenario-modeling`**, а не просмотр одиночного Factory BIM. Он заменяет прежний пункт «Сценарии»: дублирующего входа нет. Используется существующий шаблон `DefenseStudioShell`, иконка сценариев, подсветка активного раздела и `aria-current`. На мобильном экране пункт находится в общей верхней навигации. Параметры проекта сохраняются, доступность подчиняется прежнему capability `scenarios`. Дублирующая кнопка из заголовка панели удалена. Отдельный просмотр Factory BIM по `view=3d` сохранён, но пункт «Моделирование» на него не ведёт.

Проверено: scoped ESLint и `test/playwright/sidebar-collapse.cjs` прошли. На ширинах 1068/390 px проверены навигация и активное состояние; переход открывает сценарный workspace, сохраняет projectId, не показывает отдельный BIM viewer и дублирующий пункт «Сценарии». API-записей и ошибок страницы нет. Полная сборка не запускалась.

## Упрощение боковой панели моделирования — 2026-10-21

По трём комментариям пользователя удалены блок «Площадка сценария» (описание, выбор и карточка объекта, кнопка «Осмотреть объект») и блок «Подготовленные записи». Боковая панель теперь называется «Настройки просмотра». Слои карты, просмотр, сравнение и массовый прогон сохранены; данные записей не удалены. Удалены неиспользуемые стили списка записей.
