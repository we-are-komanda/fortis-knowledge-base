# ADR-0020: Стоимость конкретной ревизии и точные деньги

Дата: 2026-09-20. Принято в рамках разрешённого autonomous release run FRC-05.

## Решение

Официальная стоимость читается из сохранённой ревизии [[ADR-0018-immutable-project-revisions]]. Backend возвращает единый CostProjection с projectId/version, snapshotDigest, calculationVersion и inputDataVersions. FE запрашивает конкретную версию и целиком отображает серверные строки/группы/итог. Несохранённые изменения дают целиком маркированный draft той же арифметикой; ошибка сервера не включает локальный fallback.

Копейки хранятся/передаются десятичной строкой, расчёты выполняются целыми BigInt/big.Int; NUMERIC сохраняет точность. Legacy миллионы переводятся один раз на единицу half-up, затем применяется quantity. unitPriceMinor/customPriceMinor имеют приоритет над legacy полями; null означает неизвестность, 0 — настоящую нулевую цену. Цена экземпляра заменяет остальные; pricingMode=components суммирует явный components, не прибавляет bundle. Не выводим цену из площади, эффективности или описательного compoundProfile. Отрицательные цены, дробные количества, другая валюта отвергаются.

Размещённые позиции участвуют независимо от видимости и статуса. Группа определяется layerId, включая пользовательские слои. Неполная смета: totalMinor=null, knownSubtotalMinor отдельно. Пустая смета: полный нулевой итог.

Алгоритм cost-rub-v1 фиксируется на каждой ревизии. Cache keyed project/version/algorithm immutable, конкурентная материализация возвращает один committed result. Каждый запрос повторяет membership authorization; неизвестная версия алгоритма явно недоступна. Замена каталога не меняет прошлый snapshot. Provenance включает immutable source document revision/checksum.

## Границы

Это стоимость введённых позиций, не TCO, прогноз закупок или оценка фактической эффективности. Бюджетный запрет — FRC-07; сравнение и отчёт — FRC-08/10. Production migration/rollback/внешний runtime проверяются отдельно. Локальная приёмка и команды: parent docs/releases/2026-09-20/frc05/.
