# ADR-0028: Demo Fortis для macOS Apple Silicon

Дата: 2026-10-27. Статус: образ собран, проверен на текущем Mac; передача на другой Mac не проверена.

## Решение

По запросу пользователя создана отдельная macOS-сборка demo на Tauri с теми же моками, моделями, онлайн-картами и двумя локальными районами, что и Windows-сборка [[ADR-0027-windows-offline-demo]]. Backend Fortis не используется. В `.app` включён Node.js 22.23.4 для arm64; архив проверяется по SHA-256. Процесс стартует на loopback, закрывается с приложением и сохраняет те же ограничения demo. Разрешён локальный сетевой доступ для WKWebView.

Целевая архитектура — Apple Silicon. Проект использует ad hoc подпись для локального запуска; Developer ID и нотариализации Apple нет, поэтому системная защита может блокировать запуск после передачи. Intel-сборка и проверка на другом компьютере не выполнены.

## Проверки

Успешны production build и TypeScript, ESLint новых скриптов, smoke запуска с включённым Node, проверка офлайн-карт, целостности DMG (`hdiutil verify`) и подписи содержимого (`codesign --verify --deep --strict`). Приложение запущено на текущем Mac из копии `.app`; проверены учебные сценарии, библиотека и отображение локальной карты. Повторно выбран основной онлайн-источник карты. Finder-автоматизация при стандартной упаковке зависла; образ формируется прямым `hdiutil create` и содержит ссылку Applications.
