# ADR-0030 — подложка Яндекс Карт

Дата: 2026-11-03. Статус: интеграция подготовлена, ключ добавлен локально; проверка сервиса пока возвращает HTTP 403 Invalid api key.

По запросу пользователя добавлен официальный Yandex Tiles API как raster XYZ в существующий MapLibre/DeckGL renderer. JS API Яндекса не подключается: слои, размещение средств, BIM и общий проект Монте-Карло используют прежние координаты и взаимодействия.

Параметры: `projection=web_mercator`, `lang=ru_RU`, `l=map`, `maptype=map`, tileSize 256, zoom 0–20. Ограничение maxzoom передаётся raster source, поэтому увеличение до 1:100 не запрашивает несуществующие тайлы zoom 21+. Ключ `NEXT_PUBLIC_FORTIS_YANDEX_MAPS_API_KEY` задаётся в локальном env до запуска/сборки, не хранится в Git. Он виден браузеру и ограничивается доменами в кабинете Яндекса. Чтение публичных переменных сделано через прямые обращения `process.env.NEXT_PUBLIC_...`, чтобы Next.js включал настройки в клиентский bundle.

Источник доступен только при непустом ключе и разрешённых внешних подложках. При отсутствии сохранённого выбора Яндекс приоритетен; явный настроенный default и сохранённый выбор пользователя сохраняются. Сбой включает прежний локальный fallback. Офлайн-загрузка тайлов Яндекса не добавляется. CSP desktop разрешает только официальный домен `tiles.api-maps.yandex.ru` в img/connect; другие ограничения сохранены. Официальный локальный логотип — ссылка на Яндекс Карты.

Проверки реестра: ключ/его экранирование, проекция, zoom, default и закрытый контур; проверка сохранения выбора источника. Проверка живого сервиса требует пользовательского ключа и его активации.

Источники: [Tiles API](https://yandex.ru/maps-api/docs/tiles-api/index.html), [параметры](https://yandex.ru/maps-api/docs/tiles-api/request.html), [ограничения ключа](https://yandex.ru/maps-api/docs/tiles-api/limit.html).

## Активация и бесплатное использование

Пользователь требует бесплатную подложку. Используется бесплатный Tiles API (до 30 запросов/с); платные тарифы не подключаются. Ключ сохранён только в игнорируемом `frontend/.env.local`. Первичная проверка официального endpoint с Referer localhost вернула `403 Invalid api key`; требуется активация ключа и привязка к Tiles API. По документации активация занимает до 15 минут. Значение ключа в документации и Git не сохраняется.
