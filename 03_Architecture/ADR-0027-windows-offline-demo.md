# ADR-0027: Windows-установщик автономного demo Fortis

Дата: 2026-10-26. Статус: установщик Windows x64 собран; приёмка на Windows не выполнена.

## Требование

Пользователь запросил установочный файл Tauri, который можно передать на другой компьютер. Целевая платформа — Windows. Используем существующие моковые данные, без подключения к серверу Fortis. Работающая браузерная карта продолжает использовать локальный backend.

## Решение

В `frontend/` добавляется Tauri 2, NSIS для Windows x64. Существующий Next.js содержит server routes и динамические страницы, поэтому первая поставка включает standalone Next.js и Node.js, без переписывания frontend в static export. Это локальный процесс приложения, не подключение к удалённому backend.

Режим фиксирован как `demo`; сохраняются ограничения [[ADR-0016-runtime-backend-boundary]]. Go, PostgreSQL, серверные проекты и backend-сохранение не входят в поставку. Существующие локальные черновики остаются demo-данными.

Оболочка запускает процесс только на loopback `127.0.0.1:43178`, проверяет готовность, останавливает при закрытии. Постоянный порт сохраняет origin локальных данных. Занятый порт не освобождается принудительно. Окну не выдаются native IPC capabilities.

Поставка строится из копии исходников без `.env` и без изменения рабочего `.next`. Node.js закреплён по версии и SHA-256. Моки и модели входят в пакет.

По уточнению пользователя 2026-10-26 после проверки серого Internal basemap **географические карты должны загружаться из интернета**. Восстановлены существующие OpenFreeMap/OpenStreetMap/OpenTopoMap, их домены разрешены в CSP. Отказались от полностью офлайн-подложки. Данные Fortis остаются локальными, удалённый backend Fortis не требуется; без интернета доступен ограниченный локальный резерв, описанный ниже.

NSIS включает offline WebView2 installer. Сертификат подписи и автообновление пока не подключены. Перед передачей как проверенного релиза необходима установка на чистой Windows x64; успешной кросс-сборки недостаточно.

## Онлайн-карта с локальным резервом

Пользователь выбрал онлайн-подложку основной, а при сетевой ошибке — сообщение и автоматическое переключение на локальный участок. Полная Россия не включается. Подготовлены два района по 20×20 км вокруг demo «Завод Альфа» (37.1° E, 55.1° N) и текущего workspace «Тестовое предприятие» (40° E, 55° N), zoom 0–14, 657 уникальных тайлов и локальные шрифты/sprites, ~11.6 МБ. Первоначальная загрузка только района Альфы не покрывала workspace-объект и давала серую подложку; регрессионная проверка теперь явно проверяет покрытие обоих центров и каждый тайл в bounds. Ближайший район выбирается по текущей камере. Происхождение и контрольные суммы — `frontend/public/maps/demo-region/manifest.json`. Использованы разрешённые офлайн-загрузки OpenFreeMap, не OSM raster tile bulk download.

Fallback срабатывает на ошибку загрузки или 15-секундный timeout первоначальной загрузки. Он не меняет проект, камеру и сохранённое предпочтение онлайн-карты. В сообщении отмечены границы локального покрытия, доступны повтор онлайн и явный переход к сохранённому району. После нового запуска снова выбирается сохранённый онлайн-источник; вручную выбранная локальная карта сохраняется как предпочтение.

Сборка и проверки: `frontend/desktop/README.md`.

Исправление 2026-10-26: MapLibre требует абсолютный URL sprite до вызова transformRequest. Встроенный стиль преобразуется к текущему origin для sprite, glyphs и vector tiles; исходные файлы остаются переносимыми. Автосинхронизация выбора источника исключает временный fallback, чтобы он не перезаписывал localStorage. Browser check с заблокированными HTTPS-запросами подтвердил карту для обоих объектов, отсутствие ошибок локальных ресурсов, сохранение онлайн-предпочтения и повтор онлайн (здоровый ответ провайдера в финальном регрессионном тесте воспроизводится локальной fixture, чтобы не зависеть от задержек публичного CDN).

## Результат сборки

2026-10-26: NSIS успешно сформировал `Fortis Demo_0.1.0_x64-setup.exe`, 364.75 МиБ. Копия для передачи: `output/releases/Fortis-Windows-0.1.0/Fortis-Demo-0.1.0-Windows-x64-setup.exe` в parent workspace; рядом SHA256SUMS.txt. WebView2 offline installer включён. Пройдены production build/TypeScript, targeted ESLint, проверки состава офлайн-карт, smoke автономного процесса, browser fallback для обоих объектов. Цифровая подпись отсутствует. Фактическая установка и запуск на Windows ещё не проверены.
