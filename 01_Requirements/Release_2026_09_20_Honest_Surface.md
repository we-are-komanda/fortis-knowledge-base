# Честная рабочая поверхность Fortis — FRC-11

Принятый scope — планирование конфигураций и бюджета объекта. Точный заголовок: «Планирование конфигураций и бюджета безопасности объекта». Подзаголовок: «Соберите конфигурацию на карте, сравните сохранённые варианты и подготовьте отчёт для согласования».

Обязательное ограничение: «Расчёт составляется по введённым данным и не подтверждает фактическую эффективность системы безопасности». Нет неподтверждённых SLA, точности, экономии, гарантированной эффективности и brand-интеграций.

Единый frontend capability manifest — presentation policy, не авторизация. Новая функция переходит из not_released только после своей FRC code acceptance. Operational dashboard, retrospective/scenarios остаются demo; в workspace прямые URL дают служебное сообщение без mock customer data. Demo постоянно обозначен и требует отдельной production origin/session/storage конфигурации.

CTA ведут в workspace/login и форму демонстрации. Приём заявок disabled до выполнения [[../03_Architecture/ADR-0019-durable-demo-request-intake]]. Фактические проверки и runtime ограничения: parent docs/releases/2026-09-20/frc11. Связь: [[Release_2026_09_20_Autonomous_Run]].
